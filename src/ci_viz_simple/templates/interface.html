Test Results Query

SQL-like Query Help

Write conditions without SELECT or WHERE keywords. Available fields:

Test Info:
test_name test_fqn test_module test_suite test_file_path test_line_number
Execution:
test_status test_message test_traceback test_total_duration test_call_duration test_start_time
Git:
git_branch git_commit_hash git_commit_message git_commit_author git_commit_author_email git_commit_timestamp
Environment:
env_python_version env_platform env_architecture
CI:
ci_system ci_job_url ci_pipeline_url ci_trigger ci_pull_request_number
Session:
session_id session_start_time session_end_time session_total_duration

Examples:

  • test_name like '%test_something%' and git_branch = 'main'
  • test_status = 'failed' and test_start_time >= '2024-01-01'
  • git_commit_hash like 'abc123%' or test_status = 'skipped'
  • ci_system = 'GitHub Actions' and test_total_duration > 5.0
  • env_python_version = '3.13.0' and test_status = 'failed'
  • git_commit_author = 'Federico Mon' and test_start_time >= '2024-01-01'
